Mis à jour en novembre 2026

Qu'est-il arrivé à Messenger sur ordinateur ?

Meta a fermé ses applications Messenger pour Windows et Mac en décembre 2025, et depuis avril 2026, messenger.com te renvoie vers Facebook. Voici les dates, ce qui fonctionne encore et tes solutions.

Voir les dates Messenger sur PC aujourd'hui

En bref

Il n'existe plus d'application Messenger officielle pour ordinateur, et messenger.com ne permet plus de discuter. Sur PC, Messenger se trouve désormais sur facebook.com/messages, à l'intérieur de Facebook.

Tu peux l'utiliser dans un onglet du navigateur ou dans une application de bureau non officielle comme Chatpane, qui ouvre cette même page dans sa propre fenêtre, sans le reste de Facebook. Dans les deux cas, il te faut un compte Facebook.

Les dates

  1. 2024Meta remplace l'application native Messenger pour Windows par une version web empaquetée en application.
  2. 16 octobre 2025Meta confirme la fermeture des applications Messenger pour Windows et Mac, et les retire du Microsoft Store et du Mac App Store. Un message dans l'application demande de créer un code PIN pour pouvoir récupérer les discussions chiffrées sur le web.
  3. 15 décembre 2025Les applications de bureau cessent de fonctionner. Les personnes qui ont un compte Facebook sont envoyées vers Facebook : le site web ou, sous Windows, l'application Facebook.
  4. Février 2026Meta annonce qu'à partir d'avril, messenger.com ne servira plus à discuter et que Messenger sur ordinateur passe sur facebook.com/messages.
  5. 16 avril 2026messenger.com commence à rediriger vers facebook.com/messages. Les comptes Messenger sans profil Facebook ne peuvent plus discuter que depuis l'application mobile.

Meta n'a pas expliqué publiquement pourquoi elle a fermé les applications et messenger.com. Les applications Android et iPhone ne changent pas.

Ce qui fonctionne encore sur ordinateur

  • facebook.com/messages dans n'importe quel navigateur récent. C'est la façon officielle d'utiliser Messenger sur PC.
  • L'application Facebook pour Windows, dans le Microsoft Store. C'est tout Facebook, avec Messenger à l'intérieur.
  • Des applications de bureau non officielles qui ouvrent facebook.com/messages dans leur propre fenêtre, comme Chatpane.

Ce qui ne fonctionne plus : les anciennes applications Windows et Mac, messenger.com, les installateurs de Messenger qui traînent encore sur les sites de téléchargement, et la connexion sur ordinateur avec un compte uniquement Messenger.

Si tu n'as pas de compte Facebook

C'est le changement le plus dur. Avant, on pouvait se connecter à messenger.com avec un compte uniquement Messenger. Désormais, Meta indique que ces comptes peuvent continuer à discuter dans l'application mobile, mais que sur ordinateur il faut passer par facebook.com/messages, qui demande un compte Facebook.

Aucune application de bureau ne peut contourner cela, Chatpane non plus, car elles chargent toutes cette même page.

Questions fréquentes

Les questions qu'on se pose

Pourquoi messenger.com me renvoie-t-il vers Facebook ?

Meta a fermé messenger.com pour les discussions le 16 avril 2026. Depuis, le site t'emmène sur facebook.com/messages, le seul endroit où utiliser Messenger dans un navigateur.

Peut-on encore télécharger Messenger pour PC ?

Il n'y a pas d'application officielle. Meta l'a retirée des boutiques d'applications en octobre 2025, et elle a cessé de fonctionner le 15 décembre 2025. Les installateurs encore présents sur les sites de téléchargement sont cette application fermée. Meta recommande facebook.com/messages ou, sous Windows, l'application Facebook. Des applications non officielles comme Chatpane ouvrent facebook.com/messages dans leur propre fenêtre.

Peut-on utiliser Messenger sur ordinateur sans compte Facebook ?

Plus maintenant. Depuis la fermeture de messenger.com en avril 2026, Meta indique que les comptes sans Facebook peuvent continuer à discuter dans l'application mobile. Sur ordinateur, on passe par facebook.com/messages, qui demande un compte Facebook. Les applications non officielles chargent la même page et ont donc la même exigence.

Ai-je perdu mes discussions à la fermeture de l'application ?

En général, non. Tes discussions sont liées à ton compte : elles apparaissent sur facebook.com/messages et sur ton téléphone. L'exception, ce sont les discussions chiffrées de bout en bout : avant la fermeture, Meta a demandé de créer un code PIN de stockage sécurisé pour les récupérer sur le web. Si Messenger sur le web te demande ce code PIN, saisis-le et ton historique chiffré revient.

Pourquoi facebook.com/messages m'affiche-t-il le fil d'actualité et les Reels ?

Parce que c'est une page de Facebook. Messenger se trouve désormais sous la barre de Facebook, donc le fil d'actualité, les Reels, Marketplace et les notifications sont toujours à un clic. Des applications comme Chatpane masquent tout cela et n'affichent que tes discussions.

Chatpane est-il une application Messenger officielle ?

Non. Chatpane est un projet indépendant et open source, sans lien avec Meta. Il ouvre le vrai Messenger de facebook.com/messages dans sa propre fenêtre : tu te connectes avec ton compte habituel, et tes discussions restent synchronisées avec ton téléphone.
