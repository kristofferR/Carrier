Chatpane / Messenger

อัปเดตเดือนพฤศจิกายน 2026

เกิดอะไรขึ้นกับ Messenger บนคอม?

Meta ปิดแอป Messenger สำหรับ Windows และ Mac ในเดือนธันวาคม 2025 และตั้งแต่เดือนเมษายน 2026 messenger.com ก็พาคุณไปที่ Facebook นี่คือวันสำคัญ สิ่งที่ยังใช้ได้ และทางเลือกของคุณ

ดูไทม์ไลน์ Messenger บนคอมตอนนี้

คำตอบสั้น ๆ

ตอนนี้ไม่มีแอป Messenger ทางการสำหรับคอมแล้ว และ messenger.com ก็ใช้แชทไม่ได้อีกต่อไป บนคอม Messenger ย้ายไปอยู่ที่ facebook.com/messages ภายใน Facebook

คุณใช้ได้ทั้งในแท็บของเบราว์เซอร์ หรือในแอปเดสก์ท็อปที่ไม่ใช่ของทางการอย่าง Chatpane ซึ่งเปิดหน้าเดียวกันนี้ในหน้าต่างของตัวเองโดยไม่มีส่วนอื่นของ Facebook ทั้งสองแบบต้องใช้บัญชี Facebook

ไทม์ไลน์

  1. 2024Meta เปลี่ยนแอป Messenger แบบเนทีฟบน Windows เป็นเว็บแอปที่แพ็กมาในรูปแบบแอป
  2. 16 ตุลาคม 2025Meta ยืนยันว่าจะปิดแอป Messenger สำหรับ Windows และ Mac และถอดออกจาก Microsoft Store และ Mac App Store ข้อความในแอปขอให้ผู้ใช้ตั้ง PIN เพื่อให้กู้คืนแชทที่เข้ารหัสบนเว็บได้
  3. 15 ธันวาคม 2025แอปเดสก์ท็อปหยุดทำงาน คนที่มีบัญชี Facebook ถูกพาไปที่ Facebook: หน้าเว็บ หรือแอป Facebook บน Windows
  4. กุมภาพันธ์ 2026Meta ประกาศว่า messenger.com จะใช้แชทไม่ได้ตั้งแต่เดือนเมษายน และ Messenger บนคอมจะย้ายไปที่ facebook.com/messages
  5. 16 เมษายน 2026messenger.com เริ่มพาไปที่ facebook.com/messages บัญชี Messenger ที่ไม่มีโปรไฟล์ Facebook แชทได้เฉพาะในแอปบนมือถือ

Meta ไม่ได้ชี้แจงต่อสาธารณะว่าทำไมจึงปิดแอปและ messenger.com ส่วนแอปบน Android และ iPhone ยังใช้ได้ตามปกติ

สิ่งที่ยังใช้ได้บนคอม

  • facebook.com/messages ในเบราว์เซอร์รุ่นปัจจุบัน เป็นวิธีทางการในการใช้ Messenger บนคอม
  • แอป Facebook สำหรับ Windows ใน Microsoft Store เป็น Facebook ทั้งหมดที่มี Messenger อยู่ข้างใน
  • แอปเดสก์ท็อปที่ไม่ใช่ของทางการ ที่เปิด facebook.com/messages ในหน้าต่างของตัวเอง เช่น Chatpane

สิ่งที่ใช้ไม่ได้แล้ว: แอปเก่าบน Windows และ Mac, messenger.com, ไฟล์ติดตั้ง Messenger ที่ยังวางอยู่บนเว็บดาวน์โหลดโปรแกรม และการเข้าใช้บนคอมด้วยบัญชีที่มีแค่ Messenger

ถ้าคุณไม่มีบัญชี Facebook

นี่คือการเปลี่ยนแปลงที่กระทบหนักที่สุด เมื่อก่อนเข้า messenger.com ด้วยบัญชีที่มีแค่ Messenger ได้ ตอนนี้ Meta บอกว่าบัญชีแบบนี้ยังแชทต่อได้ในแอปบนมือถือ แต่บนคอมต้องใช้ facebook.com/messages ซึ่งต้องมีบัญชี Facebook

ไม่มีแอปเดสก์ท็อปไหนเลี่ยงข้อนี้ได้ รวมถึง Chatpane เพราะทุกแอปโหลดหน้าเดียวกันนี้

คำถามที่พบบ่อย

ข้อสงสัยที่เจอบ่อย

ทำไม messenger.com ถึงพาไปที่ Facebook?

Meta ปิด messenger.com สำหรับการแชทเมื่อ 16 เมษายน 2026 ตั้งแต่นั้นมา ถ้าเข้าไปจะถูกพาไปที่ facebook.com/messages ซึ่งเป็นที่เดียวที่ใช้ Messenger ในเบราว์เซอร์ได้

ยังโหลด Messenger ลงคอมได้อยู่ไหม?

ไม่มีแอปทางการแล้ว Meta ถอดแอปออกจากสโตร์ในเดือนตุลาคม 2025 และแอปหยุดทำงานเมื่อ 15 ธันวาคม 2025 ไฟล์ติดตั้งที่ยังมีอยู่บนเว็บดาวน์โหลดโปรแกรมก็คือแอปที่ถูกปิดไปแล้ว Meta แนะนำให้ใช้ facebook.com/messages หรือแอป Facebook บน Windows ส่วนแอปที่ไม่ใช่ของทางการอย่าง Chatpane จะเปิด facebook.com/messages ในหน้าต่างของตัวเอง

ใช้ Messenger บนคอมโดยไม่มีบัญชี Facebook ได้ไหม?

ไม่ได้แล้ว ตั้งแต่ messenger.com ปิดในเดือนเมษายน 2026 Meta บอกว่าบัญชีที่ไม่มี Facebook ยังแชทต่อได้ในแอปบนมือถือ ส่วนบนคอมต้องใช้ facebook.com/messages ซึ่งต้องมีบัญชี Facebook แอปที่ไม่ใช่ของทางการโหลดหน้าเดียวกันนี้ จึงมีเงื่อนไขเดียวกัน

แชทหายไหมตอนที่แอปปิด?

โดยปกติไม่หาย แชทอยู่ในบัญชีของคุณ จึงขึ้นทั้งใน facebook.com/messages และบนมือถือ ยกเว้นแชทที่เข้ารหัสต้นทางถึงปลายทาง ก่อนปิดแอป Meta ขอให้ตั้ง PIN สำหรับพื้นที่จัดเก็บที่ปลอดภัยเพื่อกู้คืนแชทเหล่านี้บนเว็บ ถ้า Messenger บนเว็บถาม PIN นี้ ใส่แล้วประวัติแชทที่เข้ารหัสจะกลับมา

ทำไม facebook.com/messages ถึงมีฟีดและ Reels?

เพราะเป็นหน้าหนึ่งใน Facebook ตอนนี้ Messenger อยู่ใต้แถบเมนูของ Facebook ฟีด Reels Marketplace และการแจ้งเตือนจึงอยู่ห่างแค่คลิกเดียวเสมอ แอปอย่าง Chatpane ซ่อนทั้งหมดนี้และแสดงแค่แชทของคุณ

Chatpane เป็นแอป Messenger ทางการหรือเปล่า?

ไม่ใช่ Chatpane เป็นโปรเจกต์อิสระแบบโอเพนซอร์ส ไม่เกี่ยวข้องกับ Meta แอปนี้เปิด Messenger ตัวจริงจาก facebook.com/messages ในหน้าต่างของตัวเอง คุณจึงล็อกอินด้วยบัญชีเดิม และแชทก็ซิงก์กับมือถือ
