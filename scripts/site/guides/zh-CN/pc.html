2026 年怎样在电脑上用 Messenger

Meta 已在 2025 年 12 月 15 日停用 Windows 版 Messenger 应用，messenger.com 现在也会把你转到 Facebook。下面是如今在 Windows 10 或 11 电脑、笔记本上还能用的方法。

免费开源 · Windows 10 和 11 · 不是 Meta 的应用

简短回答

官方的 Messenger 电脑版已经没有了。Meta 把它从 Microsoft Store 下架，从 2026 年 4 月起，电脑上的 Messenger 只能在 Facebook 里面的 facebook.com/messages 使用。

如果你想让 Messenger 有自己的窗口，不看动态和 Reels，Chatpane 是一款免费、开源的 Windows 应用，只显示你的聊天，别的都不显示。它是独立项目，不是 Meta 的应用。

小心下载站里的“Messenger 电脑版”

不少旧教程还在叫你去 Microsoft Store 找 Messenger，很多下载站也还在提供“Messenger 2250.1”安装包。这正是 Meta 在 2025 年 12 月停用的那个应用：打开后只会把你转到 Facebook，装了也没用。

另外，不要在来路不明的程序或网页里输入你的 Facebook 密码。如果有人给你一个自带登录界面的“Messenger 电脑版”，请多加小心。

Windows 版 Messenger 怎么了？

2024 年，Meta 把原生的 Windows 应用换成了打包的网页版。2025 年 10 月，Meta 宣布停用并把它从 Microsoft Store 下架，2025 年 12 月 15 日它就不能用了。2026 年 4 月，messenger.com 也关闭了。详细日期见 Messenger 电脑版为什么不能用了。

你的选择

在 Windows 上使用 Messenger 的几种方法

无需安装

浏览器

在 Chrome 或 Edge 中打开 facebook.com/messages。这是 Meta 的官方方式，什么都不用装。

  • Facebook 的导航栏、通知和动态始终近在一键之遥
  • 容易淹没在一堆标签页里，关掉浏览器它也跟着关
无需安装

用 Edge 或 Chrome 安装成应用

打开 facebook.com/messages，在浏览器菜单里选择把此页面安装为应用。这样就有了独立窗口和任务栏图标。

  • 里面仍然是完整的 Facebook 页面
官方

Facebook 应用

这是 Meta 在 Windows 上推荐的方式，可从 Microsoft Store 获取。Messenger 是其中的一部分，也能通话。

  • 整个 Facebook 都在里面：动态、Reels 和 Marketplace
推荐

Chatpane

一款不到 4 MB 的 Windows 应用，只显示你的聊天。它使用 Windows 自带的网页引擎，不用再装一整个浏览器。

  • 直接在通知里回复、回应或静音
  • 任务栏图标上显示未读数
  • 菜单和设置都是简体中文

Windows 上的 Chatpane

Chatpane 打开的就是你在浏览器里用的那个 Messenger，所以聊天、群组、通话和照片都在，并且和手机保持同步。它去掉的只是 Facebook 的其他部分。

  • 只有 Messenger。Facebook 的动态、Reels、Marketplace 和搜索都被隐藏。
  • 好用的通知。不用打开窗口，就能在通知里回复、用表情回应、标为已读或静音。在 Marketplace 上卖东西的话，也不会错过买家的消息。
  • 任务栏和系统托盘。图标上显示未读消息数，可以开机自动启动，关闭窗口后还能选择在系统托盘中继续运行。
  • 隐私。隐藏“正在输入”，共享屏幕时隐藏名字和头像，并拦截 Facebook 的分析请求（默认开启）。
  • 开源。Chatpane 以 MIT 许可开源，代码放在 GitHub 上，谁都可以查看它到底做了什么。
  • 说你的语言。Chatpane 跟随电脑的语言，所以菜单和设置会以简体中文显示。也可以在“设置”→“通用”→“语言”中换成别的语言。

安装方法

  1. 下载 Windows 安装程序。如果你的电脑是 ARM 处理器，请用 ARM64 安装程序。
  2. 运行它。Chatpane 的 Windows 安装程序还没有数字签名，所以 SmartScreen 可能会显示“Windows 已保护你的电脑”。先点“更多信息”，再点“仍要运行”。请只从 chatpane.app 或 GitHub 下载 Chatpane。
  3. 用你平时的 Facebook 账号登录，聊天马上就会出现。

不想安装？便携版（.zip）解压即可使用，不需要管理员权限。

常见问题

关于 Messenger 电脑版的问题

Chatpane 免费吗？

免费。没有标价、没有订阅，也没有广告。Chatpane 以 MIT 许可开源，代码公开在 GitHub 上，谁都可以检查。

这是官方的 Messenger 应用吗？

不是。Chatpane 是独立项目，与 Meta 没有任何关联。它在自己的窗口里显示 facebook.com/messages 上真正的 Messenger，所以你的消息仍然经由 Messenger 传送，也仍适用 Meta 的条款。

没有 Facebook 账号能用吗？

不能。从 2026 年 4 月起，Meta 只允许没有 Facebook 账号的人在手机应用里使用 Messenger。在电脑上，Chatpane 和其他任何方法都需要一个能登录 facebook.com 的账号。

Windows 10 能用吗？

能，Windows 10 和 11 都可以。Chatpane 使用 Microsoft Edge WebView2，Windows 11 已经自带。在 Windows 10 上，如果缺少它，安装程序会自动下载。

能打语音和视频电话吗？

能。这就是完整的 Messenger，所以语音和视频通话会在单独的窗口中打开，和在 facebook.com 上一样。
