Chatpane / Windows

၂၀၂၆ ခုနှစ် နိုဝင်ဘာလ အပ်ဒိတ်

၂၀၂၆ မှာ ကွန်ပျူတာပေါ် Messenger သုံးနည်း

Meta က Windows အတွက် Messenger app ကို ၂၀၂၅ ခုနှစ် ဒီဇင်ဘာလ ၁၅ ရက်နေ့မှာ ပိတ်လိုက်ပြီး၊ အခု messenger.com ကလည်း Facebook ကို ပို့ပေးနေပါတယ်။ Windows 10 ဒါမှမဟုတ် 11 သုံးတဲ့ ကွန်ပျူတာ၊ laptop တွေမှာ အခု အလုပ်လုပ်နေသေးတဲ့ နည်းလမ်းတွေက ဒီမှာပါ။

Windows အတွက် Chatpane ဒေါင်းလုဒ် နည်းလမ်းအားလုံး ကြည့်ရန်

အခမဲ့၊ open-source · Windows 10 နဲ့ 11 · Meta ရဲ့ app မဟုတ်ပါ

အတိုချုပ် အဖြေ

ကွန်ပျူတာအတွက် တရားဝင် Messenger app မရှိတော့ပါဘူး။ Meta က Microsoft Store ကနေ ဖြုတ်လိုက်ပြီး၊ ၂၀၂၆ ခုနှစ် ဧပြီလကစပြီး ကွန်ပျူတာပေါ်က Messenger ဟာ Facebook ထဲက facebook.com/messages မှာပဲ အလုပ်လုပ်ပါတော့တယ်။

Feed တွေ Reels တွေ မပါဘဲ Messenger ကို သီးသန့် window တစ်ခုထဲမှာ သုံးချင်ရင် Chatpane ဟာ သင့်စကားပြောခန်းတွေကိုပဲ ဖွင့်ပေးတဲ့ Windows အတွက် အခမဲ့ open-source app တစ်ခုပါ။ သီးခြား project တစ်ခုဖြစ်ပြီး Meta ရဲ့ app မဟုတ်ပါဘူး။

လမ်းညွှန်အဟောင်းတွေ ဘာကြောင့် မရတော့တာလဲ

လမ်းညွှန်တော်တော်များများက Microsoft Store မှာ "Messenger" ကို ရှာခိုင်းတာ၊ ဒါမှမဟုတ် software ဒေါင်းလုဒ်ဆိုက်တွေကနေ Messenger 2250.1 installer ကို ဒေါင်းခိုင်းတာ ရှိနေသေးပါတယ်။ အဲဒီနည်းက မရတော့ပါဘူး။ အဲဒါက Meta က ၂၀၂၅ ခုနှစ် ဒီဇင်ဘာလမှာ ပိတ်လိုက်တဲ့ app ပဲ ဖြစ်ပြီး၊ ဖွင့်လိုက်ရင် Facebook ကိုပဲ ပို့ပေးပါတယ်။

ဘယ်ကလာမှန်းမသိတဲ့ program ဒါမှမဟုတ် စာမျက်နှာထဲမှာ သင့် Facebook စကားဝှက်ကို မရိုက်ထည့်ပါနဲ့။ ကိုယ်ပိုင် login စာမျက်နှာပါတဲ့ "PC အတွက် Messenger" ကို တစ်ယောက်ယောက်က ပေးလာရင် သတိထားပါ။

Windows အတွက် Messenger ဘာဖြစ်သွားတာလဲ

၂၀၂၄ ခုနှစ်မှာ Meta က Windows app ကို app ပုံစံထုပ်ထားတဲ့ web version နဲ့ အစားထိုးခဲ့ပါတယ်။ ၂၀၂၅ ခုနှစ် အောက်တိုဘာလမှာ ပိတ်မယ်လို့ ကြေညာပြီး Microsoft Store ကနေ ဖြုတ်ခဲ့တယ်၊ ဒီဇင်ဘာလ ၁၅ ရက်နေ့မှာ app အလုပ်မလုပ်တော့ပါဘူး။ ၂၀၂၆ ခုနှစ် ဧပြီလမှာ messenger.com ကိုလည်း ပိတ်လိုက်ပါတယ်။ အသေးစိတ်နဲ့ ရက်စွဲတွေကို ကွန်ပျူတာပေါ်က Messenger ဘာဖြစ်သွားတာလဲ မှာ ဖတ်နိုင်ပါတယ်။

သင့်ရွေးချယ်စရာများ

Windows မှာ Messenger သုံးနိုင်တဲ့ နည်းလမ်းများ

install မလို

Browser

Chrome ဒါမှမဟုတ် Edge မှာ facebook.com/messages ကို ဖွင့်ပါ။ ဒါက Meta ရဲ့ တရားဝင်နည်းလမ်းဖြစ်ပြီး ဘာမှ install လုပ်စရာ မလိုပါဘူး။

  • Facebook ရဲ့ menu bar၊ အသိပေးချက်တွေနဲ့ Feed က တစ်ချက်နှိပ်ရုံ အကွာမှာ ရှိနေတယ်
  • တခြား tab တွေကြားမှာ ရောနေပြီး browser ပိတ်ရင် အတူပိတ်သွားတယ်
install မလို

Edge ဒါမှမဟုတ် Chrome ကနေ app အဖြစ် ထည့်ခြင်း

facebook.com/messages မှာ browser ရဲ့ menu ကိုဖွင့်ပြီး ဒီစာမျက်နှာကို app အဖြစ် install လုပ်တဲ့ option ကို ရွေးပါ။ သီးသန့် window တစ်ခုနဲ့ taskbar ပေါ်မှာ icon တစ်ခု ရပါမယ်။

  • အထဲမှာတော့ Facebook စာမျက်နှာ အပြည့်အစုံပဲ ဖြစ်နေဆဲပါ
တရားဝင်

Facebook app

Windows မှာ Meta အကြံပြုတာက Microsoft Store က Facebook app ပါ။ ခေါ်ဆိုမှုတွေအပါအဝင် Messenger ဟာ အဲဒီ app ထဲက အပိုင်းတစ်ခုပါ။

  • Feed၊ Reels နဲ့ Marketplace အပါအဝင် Facebook တစ်ခုလုံး ပါလာတယ်
အကြံပြု

Chatpane

သင့်စကားပြောခန်းတွေကိုပဲ ပြပေးတဲ့ 4 MB မပြည့်တဲ့ Windows app ပါ။ browser တစ်ခုလုံး ထပ်ထည့်မယ့်အစား Windows မှာ ပါပြီးသား web engine ကို သုံးပါတယ်။

  • အသိပေးချက်ကနေ စာပြန်၊ react လုပ် ဒါမှမဟုတ် အသံပိတ်နိုင်
  • taskbar ပေါ်မှာ မဖတ်ရသေးတဲ့ အရေအတွက်
  • menu နဲ့ ဆက်တင်တွေ မြန်မာလို ရနိုင်

Windows ပေါ်က Chatpane

Chatpane က browser ထဲမှာ မြင်နေကျ Messenger အတူတူကိုပဲ ဖွင့်ပေးတာမို့ သင့်စကားပြောခန်း၊ group၊ ခေါ်ဆိုမှုနဲ့ ဓာတ်ပုံတွေ အားလုံး ရှိနေပြီး ဖုန်းနဲ့လည်း sync ဖြစ်ပါတယ်။ ဖယ်ထုတ်လိုက်တာက Facebook ရဲ့ ကျန်တဲ့အပိုင်းတွေပါ။

  • Messenger သက်သက်။ Facebook ရဲ့ Feed၊ Reels၊ Marketplace နဲ့ ရှာဖွေမှုကို ဖျောက်ထားပါတယ်။
  • အသုံးဝင်တဲ့ အသိပေးချက်။ window ကို မဖွင့်ဘဲ အသိပေးချက်ကနေ တိုက်ရိုက် စာပြန်၊ react လုပ်၊ ဖတ်ပြီးဟု မှတ် ဒါမှမဟုတ် အသံပိတ်နိုင်ပါတယ်။ ကွန်ပျူတာနဲ့ အလုပ်လုပ်ရင်း Messenger နဲ့ Viber ကို တစ်ပြိုင်နက် ပြန်ရတဲ့အခါ အဆင်ပြေပါတယ်။
  • Taskbar နဲ့ tray။ icon ပေါ်မှာ မဖတ်ရသေးတဲ့ အရေအတွက်၊ Windows နဲ့အတူ စတင်ခြင်း၊ window ပိတ်လိုက်ရင်လည်း tray ထဲမှာ ဆက် run နေစေနိုင်ခြင်း။
  • ကိုယ်ရေးကိုယ်တာ။ စာရိုက်နေတာကို ဖျောက်ထားခြင်း၊ screen share လုပ်တဲ့အခါ အမည်နဲ့ ပရိုဖိုင်ပုံတွေ ဖျောက်ခြင်း၊ Facebook ရဲ့ analytics တောင်းဆိုမှုတွေကို ပိတ်ခြင်း (မူလအတိုင်း ဖွင့်ထားပြီး)။
  • မြန်မာဘာသာ။ Chatpane က ကွန်ပျူတာရဲ့ ဘာသာစကားအတိုင်း ပြပြီး menu နဲ့ ဆက်တင်တွေကို မြန်မာလို ဘာသာပြန်ထားပါတယ်။ Windows ကို English နဲ့ သုံးနေရင် ဆက်တင်များ → အထွေထွေ → ဘာသာစကား မှာ မြန်မာကို ရွေးနိုင်ပါတယ်။

Install လုပ်နည်း

  1. Windows installer ကို ဒေါင်းလုဒ်လုပ်ပါ။ သင့်ကွန်ပျူတာက ARM chip သုံးရင် ARM64 installer ကို သုံးပါ။
  2. ဖိုင်ကို ဖွင့်ပါ။ Chatpane ရဲ့ Windows installer တွေမှာ digital signature မပါသေးလို့ SmartScreen က "Windows protected your PC" လို့ ပြနိုင်ပါတယ်။ "More info" ကိုနှိပ်ပြီး "Run anyway" ကို နှိပ်ပါ။ Chatpane ကို chatpane.app ဒါမှမဟုတ် GitHub ကနေပဲ ဒေါင်းလုဒ်လုပ်ပါ။
  3. သင်အမြဲသုံးနေကျ Facebook အကောင့်နဲ့ ဝင်ပါ။ စကားပြောခန်းတွေ ချက်ချင်း ပေါ်လာပါမယ်။

ဘာမှ install မလုပ်ချင်ဘူးလား။ Portable version (.zip) က install မလုပ်ဘဲ သုံးလို့ရပါတယ်။

မေးခွန်းများ

ကွန်ပျူတာပေါ်က Messenger အကြောင်း မေးခွန်းများ

Chatpane က အခမဲ့လား?

ဟုတ်ပါတယ်။ ငွေပေးစရာ မရှိ၊ subscription မရှိ၊ ကြော်ငြာ မရှိပါဘူး။ MIT license နဲ့ open-source ဖြစ်ပြီး code ကို GitHub မှာ ဘယ်သူမဆို စစ်ဆေးနိုင်အောင် တင်ထားပါတယ်။

ဒါ တရားဝင် Messenger app လား?

မဟုတ်ပါဘူး။ Chatpane ဟာ Meta နဲ့ မသက်ဆိုင်တဲ့ သီးခြား project တစ်ခုပါ။ facebook.com/messages က Messenger အစစ်ကို ကိုယ်ပိုင် window ထဲမှာ ပြပေးတာမို့ သင့်မက်ဆေ့ချ်တွေက Messenger ကနေပဲ သွားပြီး Meta ရဲ့ စည်းကမ်းချက်တွေလည်း သက်ရောက်နေဆဲပါ။

Facebook အကောင့် မရှိရင် သုံးလို့ရလား?

မရပါဘူး။ ၂၀၂၆ ခုနှစ် ဧပြီလကစပြီး Facebook အကောင့်မပါဘဲ Messenger သုံးတာကို Meta က ဖုန်း app မှာပဲ ခွင့်ပြုပါတော့တယ်။ ကွန်ပျူတာပေါ်မှာတော့ Chatpane အပါအဝင် ဘယ်နည်းလမ်းမဆို facebook.com ကို ဝင်လို့ရတဲ့ အကောင့် လိုပါတယ်။

Windows 10 မှာ အလုပ်လုပ်လား?

လုပ်ပါတယ်၊ Windows 10 နဲ့ 11 နှစ်ခုလုံးမှာပါ။ Chatpane က Windows 11 မှာ ပါပြီးသား Microsoft Edge WebView2 ကို သုံးပါတယ်။ Windows 10 မှာ မရှိသေးရင် installer က ဒေါင်းလုဒ်လုပ်ပေးပါတယ်။

ဗီဒီယိုခေါ်ဆိုမှု လုပ်လို့ရလား?

ရပါတယ်။ ဒါ Messenger အပြည့်အစုံမို့ အသံခေါ်ဆိုမှုနဲ့ ဗီဒီယိုခေါ်ဆိုမှုတွေဟာ facebook.com မှာလိုပဲ ကိုယ်ပိုင် window ထဲမှာ ပွင့်လာပါတယ်။
