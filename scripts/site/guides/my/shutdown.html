Chatpane / Messenger

၂၀၂၆ ခုနှစ် နိုဝင်ဘာလ အပ်ဒိတ်

ကွန်ပျူတာပေါ်က Messenger ဘာဖြစ်သွားတာလဲ?

Meta က Windows နဲ့ Mac အတွက် Messenger app တွေကို ၂၀၂၅ ခုနှစ် ဒီဇင်ဘာလမှာ ပိတ်လိုက်ပြီး၊ ၂၀၂၆ ခုနှစ် ဧပြီလကစပြီး messenger.com က Facebook ကို ပို့ပေးနေပါတယ်။ ရက်စွဲတွေ၊ အလုပ်လုပ်နေသေးတာတွေနဲ့ သင့်ရွေးချယ်စရာတွေက ဒီမှာပါ။

ရက်စွဲများ ကြည့်ရန် အခု ကွန်ပျူတာမှာ Messenger

အတိုချုပ် အဖြေ

ကွန်ပျူတာအတွက် တရားဝင် Messenger app မရှိတော့သလို messenger.com မှာလည်း chat လို့ မရတော့ပါဘူး။ ကွန်ပျူတာပေါ်မှာ Messenger က အခု Facebook ထဲက facebook.com/messages မှာ ရှိပါတယ်။

Browser tab တစ်ခုမှာ သုံးနိုင်သလို၊ အဲဒီစာမျက်နှာကိုပဲ Facebook ရဲ့ ကျန်တဲ့အပိုင်းတွေမပါဘဲ ကိုယ်ပိုင် window ထဲမှာ ဖွင့်ပေးတဲ့ Chatpane လို တရားဝင်မဟုတ်တဲ့ desktop app နဲ့လည်း သုံးနိုင်ပါတယ်။ ဘယ်နည်းမဆို Facebook အကောင့် လိုပါတယ်။

ရက်စွဲများ

  1. ၂၀၂၄ ခုနှစ်Meta က Windows အတွက် native Messenger app ကို app ပုံစံထုပ်ထားတဲ့ web version နဲ့ အစားထိုးခဲ့ပါတယ်။
  2. ၂၀၂၅ ခုနှစ် အောက်တိုဘာ ၁၆Windows နဲ့ Mac အတွက် Messenger app တွေကို ပိတ်မယ်လို့ Meta က အတည်ပြုပြီး Microsoft Store နဲ့ Mac App Store ကနေ ဖြုတ်ခဲ့ပါတယ်။ ကုဒ်ဝှက်ထားတဲ့ chat တွေကို web ပေါ်မှာ ပြန်ယူနိုင်ဖို့ PIN တစ်ခု သတ်မှတ်ထားဖို့ app ထဲမှာ အသိပေးခဲ့ပါတယ်။
  3. ၂၀၂၅ ခုနှစ် ဒီဇင်ဘာ ၁၅Desktop app တွေ အလုပ်မလုပ်တော့ပါဘူး။ Facebook အကောင့်ရှိသူတွေကို Facebook ဆီ ပို့ပေးခဲ့ပါတယ်၊ website ဒါမှမဟုတ် Windows မှာဆိုရင် Facebook app ဆီပါ။
  4. ၂၀၂၆ ခုနှစ် ဖေဖော်ဝါရီmessenger.com မှာ ဧပြီလကစပြီး chat လို့ မရတော့ဘဲ ကွန်ပျူတာပေါ်က Messenger က facebook.com/messages ကို ပြောင်းမယ်လို့ Meta က ကြေညာခဲ့ပါတယ်။
  5. ၂၀၂၆ ခုနှစ် ဧပြီ ၁၆messenger.com က facebook.com/messages ကို စတင် ပို့ပေးပါတယ်။ Facebook profile မရှိတဲ့ Messenger အကောင့်တွေက ဖုန်း app မှာပဲ chat လို့ရပါတော့တယ်။

App တွေနဲ့ messenger.com ကို ဘာကြောင့် ပိတ်လိုက်တာလဲဆိုတာ Meta က လူသိရှင်ကြား ရှင်းပြခဲ့ခြင်း မရှိပါဘူး။ Android နဲ့ iPhone app တွေကတော့ အရင်အတိုင်းပါပဲ။

ကွန်ပျူတာပေါ်မှာ အလုပ်လုပ်နေသေးတာတွေ

  • ခေတ်မီ browser တစ်ခုခုမှာ facebook.com/messages။ ကွန်ပျူတာပေါ်မှာ Messenger သုံးဖို့ တရားဝင်နည်းလမ်းပါ။
  • Microsoft Store က Windows အတွက် Facebook app။ Messenger ပါဝင်တဲ့ Facebook တစ်ခုလုံးပါ။
  • facebook.com/messages ကို ကိုယ်ပိုင် window ထဲမှာ ဖွင့်ပေးတဲ့ Chatpane လို တရားဝင်မဟုတ်တဲ့ desktop app များ။

အလုပ်မလုပ်တော့တာတွေ- Windows နဲ့ Mac app အဟောင်းတွေ၊ messenger.com၊ software ဒေါင်းလုဒ်ဆိုက်တွေမှာ ရှိနေသေးတဲ့ Messenger installer တွေနဲ့ Messenger သက်သက်အကောင့်နဲ့ ကွန်ပျူတာကနေ ဝင်ခြင်း။

Facebook အကောင့် မရှိရင်

ဒါက အကြီးဆုံး အပြောင်းအလဲပါ။ အရင်က Messenger သက်သက်အကောင့်နဲ့ messenger.com ကို ဝင်လို့ရခဲ့ပါတယ်။ အခု Meta ပြောတာက အဲဒီလို အကောင့်တွေဟာ ဖုန်း app မှာ ဆက် chat လို့ရပေမယ့် ကွန်ပျူတာပေါ်မှာတော့ Facebook အကောင့်လိုတဲ့ facebook.com/messages ကို သုံးရမှာပါ။

Desktop app တွေအားလုံးက အဲဒီစာမျက်နှာကိုပဲ ဖွင့်တာမို့ Chatpane အပါအဝင် ဘယ် app မှ ဒါကို ရှောင်လို့ မရပါဘူး။

  • Meta အကူအညီစင်တာ: messenger.com အပြောင်းအလဲများ

မေးခွန်းများ

မကြာခဏ မေးလေ့ရှိတဲ့ မေးခွန်းများ

messenger.com က ဘာကြောင့် Facebook ကို ပို့နေတာလဲ?

Meta က ၂၀၂၆ ခုနှစ် ဧပြီလ ၁၆ ရက်နေ့မှာ messenger.com ကို chat အတွက် ပိတ်လိုက်ပါတယ်။ အဲဒီကစပြီး အဲဒီကို ဝင်ရင် browser ထဲမှာ Messenger သုံးလို့ရတဲ့ တစ်ခုတည်းသောနေရာ ဖြစ်တဲ့ facebook.com/messages ကို ရောက်သွားပါတယ်။

ကွန်ပျူတာအတွက် Messenger ကို ဒေါင်းလုဒ်လုပ်လို့ ရသေးလား?

တရားဝင် app မရှိတော့ပါဘူး။ Meta က ၂၀၂၅ ခုနှစ် အောက်တိုဘာလမှာ store တွေကနေ ဖြုတ်ပြီး ဒီဇင်ဘာလ ၁၅ ရက်နေ့မှာ အလုပ်မလုပ်တော့ပါဘူး။ ဒေါင်းလုဒ်ဆိုက်တွေမှာ ရှိနေသေးတဲ့ installer တွေက အဲဒီ ပိတ်လိုက်တဲ့ app ပါပဲ။ Meta က facebook.com/messages ဒါမှမဟုတ် Windows မှာ Facebook app ကို အကြံပြုပါတယ်။ Chatpane လို တရားဝင်မဟုတ်တဲ့ app တွေက facebook.com/messages ကို ကိုယ်ပိုင် window ထဲမှာ ဖွင့်ပေးပါတယ်။

Facebook အကောင့်မပါဘဲ ကွန်ပျူတာမှာ Messenger သုံးလို့ရလား?

မရတော့ပါဘူး။ ၂၀၂၆ ခုနှစ် ဧပြီလမှာ messenger.com ပိတ်သွားကတည်းက Facebook မပါတဲ့ အကောင့်တွေဟာ ဖုန်း app မှာ ဆက် chat လို့ရတယ်လို့ Meta က ပြောပါတယ်။ ကွန်ပျူတာပေါ်မှာတော့ Facebook အကောင့်လိုတဲ့ facebook.com/messages ကို သုံးရပါတယ်။ တရားဝင်မဟုတ်တဲ့ app တွေလည်း အဲဒီစာမျက်နှာကိုပဲ ဖွင့်တာမို့ လိုအပ်ချက် အတူတူပါပဲ။

App ပိတ်သွားတော့ chat တွေ ပျောက်သွားလား?

ပုံမှန်အားဖြင့် မပျောက်ပါဘူး။ Chat တွေက သင့်အကောင့်ထဲမှာ ရှိတာမို့ facebook.com/messages နဲ့ ဖုန်းမှာ ပေါ်ပါတယ်။ ခြွင်းချက်က end-to-end ကုဒ်ဝှက်ထားတဲ့ chat တွေပါ။ App မပိတ်ခင် Meta က web ပေါ်မှာ အဲဒါတွေ ပြန်ယူနိုင်ဖို့ secure storage PIN သတ်မှတ်ခိုင်းခဲ့ပါတယ်။ Web ပေါ်က Messenger က အဲဒီ PIN ကို တောင်းရင် ထည့်လိုက်တာနဲ့ ကုဒ်ဝှက်ထားတဲ့ chat မှတ်တမ်းတွေ ပြန်ပေါ်လာပါမယ်။

facebook.com/messages မှာ Feed နဲ့ Reels ဘာကြောင့် ပေါ်နေတာလဲ?

အဲဒါက Facebook ထဲက စာမျက်နှာတစ်ခု ဖြစ်လို့ပါ။ အခု Messenger က Facebook ရဲ့ menu bar အောက်မှာ ရှိတာမို့ Feed၊ Reels၊ Marketplace နဲ့ အသိပေးချက်တွေက အမြဲ တစ်ချက်နှိပ်ရုံ အကွာမှာ ရှိနေပါတယ်။ Chatpane လို app တွေက အဲဒါတွေကို ဖျောက်ပြီး သင့် chat တွေကိုပဲ ပြပေးပါတယ်။

Chatpane က တရားဝင် Messenger app လား?

မဟုတ်ပါဘူး။ Chatpane ဟာ Meta နဲ့ မသက်ဆိုင်တဲ့ သီးခြား open-source project တစ်ခုပါ။ facebook.com/messages က Messenger အစစ်ကို ကိုယ်ပိုင် window ထဲမှာ ဖွင့်ပေးတာမို့ သင်အမြဲသုံးနေကျ အကောင့်နဲ့ ဝင်ရပြီး chat တွေကလည်း ဖုန်းနဲ့ sync ဖြစ်ပါတယ်။
