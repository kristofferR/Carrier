ວິທີໃຊ້ Messenger ຢູ່ຄອມໃນປີ 2026

Meta ປິດແອັບ Messenger ສຳລັບ Windows ໄປຕັ້ງແຕ່ວັນທີ 15 ທັນວາ 2025, ແລະ ຕອນນີ້ messenger.com ກໍພາເຈົ້າໄປ Facebook ແທນ. ນີ້ແມ່ນວິທີທີ່ຍັງໃຊ້ໄດ້ຢູ່ຄອມ ແລະ ໂນດບຸກທີ່ໃຊ້ Windows 10 ຫຼື 11.

ດາວໂຫຼດ Chatpane ສຳລັບ Windows ເບິ່ງທາງເລືອກທັງໝົດ

ຟຣີ ແລະ ເປັນໂອເພນຊອດ · Windows 10 ແລະ 11 · ບໍ່ແມ່ນແອັບຂອງ Meta

ຄຳຕອບສັ້ນໆ

ຕອນນີ້ບໍ່ມີແອັບ Messenger ທາງການສຳລັບຄອມອີກແລ້ວ. Meta ເອົາແອັບອອກຈາກ Microsoft Store, ແລະ ຕັ້ງແຕ່ເດືອນເມສາ 2026 Messenger ຢູ່ຄອມໃຊ້ໄດ້ສະເພາະຢູ່ facebook.com/messages ເຊິ່ງຢູ່ພາຍໃນ Facebook ເທົ່ານັ້ນ.

ຖ້າເຈົ້າຢາກໄດ້ Messenger ໃນໜ້າຕ່າງຂອງມັນເອງ ໂດຍບໍ່ມີ Feed ຫຼື Reels ມາລົບກວນ, Chatpane ແມ່ນແອັບຟຣີແບບໂອເພນຊອດສຳລັບ Windows ທີ່ເປີດແຕ່ແຊັດຂອງເຈົ້າ. ມັນເປັນໂປຣເຈັກອິດສະຫຼະ, ບໍ່ແມ່ນຂອງ Meta.

ເປັນຫຍັງວິທີດາວໂຫຼດແບບເກົ່າຈຶ່ງໃຊ້ບໍ່ໄດ້ແລ້ວ

ບົດຄວາມສອນດາວໂຫຼດ Messenger ໃສ່ຄອມຫຼາຍບ່ອນ ຍັງບອກໃຫ້ຊອກຫາ "Messenger" ໃນ Microsoft Store ຫຼື ດາວໂຫຼດໄຟລ໌ຕິດຕັ້ງ Messenger 2250.1 ຈາກເວັບດາວໂຫຼດໂປຣແກຣມ. ວິທີນີ້ບໍ່ໄດ້ຜົນແລ້ວ ເພາະນັ້ນແມ່ນແອັບທີ່ Meta ປິດໄປໃນເດືອນທັນວາ 2025. ເປີດຂຶ້ນມາກໍພຽງແຕ່ພາເຈົ້າໄປ Facebook.

ແລະ ຢ່າໃສ່ລະຫັດຜ່ານ Facebook ໃນໂປຣແກຣມ ຫຼື ໜ້າເວັບທີ່ບໍ່ຮູ້ທີ່ມາ. ຖ້າມີໃຜສະເໜີ "Messenger ສຳລັບ PC" ທີ່ມີໜ້າລ໋ອກອິນຂອງໂຕເອງ, ໃຫ້ລະວັງໄວ້ກ່ອນ.

ເກີດຫຍັງຂຶ້ນກັບ Messenger ສຳລັບ Windows?

ໃນປີ 2024 Meta ປ່ຽນແອັບ Windows ເປັນເວັບແອັບທີ່ຫໍ່ມາເປັນແອັບ. ໃນເດືອນຕຸລາ 2025 Meta ປະກາດປິດ ແລະ ເອົາອອກຈາກ Microsoft Store, ແລ້ວແອັບກໍຢຸດເຮັດວຽກໃນວັນທີ 15 ທັນວາ 2025. ໃນເດືອນເມສາ 2026 messenger.com ກໍປິດຕາມໄປ. ອ່ານລາຍລະອຽດ ແລະ ວັນທີທັງໝົດໄດ້ທີ່ ເກີດຫຍັງຂຶ້ນກັບ Messenger ຢູ່ຄອມ.

Chatpane ຢູ່ Windows

Chatpane ເປີດ Messenger ໂຕດຽວກັບທີ່ເຈົ້າເຫັນໃນບຣາວເຊີ, ສະນັ້ນ ແຊັດ, ກຸ່ມ, ການໂທ ແລະ ຮູບພາບຂອງເຈົ້າຈຶ່ງຢູ່ຄົບ ແລະ ຊິງກັບມືຖືຂອງເຈົ້າ. ສິ່ງທີ່ມັນເອົາອອກແມ່ນສ່ວນອື່ນທັງໝົດຂອງ Facebook.

  • ສະເພາະ Messenger. Feed, Reels, Marketplace ແລະ ຊ່ອງຄົ້ນຫາຂອງ Facebook ຖືກເຊື່ອງໄວ້.
  • ການແຈ້ງເຕືອນທີ່ໃຊ້ໄດ້ແທ້. ຕອບກັບ, ສະແດງຄວາມຮູ້ສຶກ, ໝາຍວ່າອ່ານແລ້ວ ຫຼື ປິດສຽງໄດ້ຈາກການແຈ້ງເຕືອນ ໂດຍບໍ່ຕ້ອງເປີດໜ້າຕ່າງ. ສະດວກເວລາເຮັດວຽກຢູ່ຄອມ ແລະ ຕ້ອງຕອບແຊັດໄປພ້ອມກັນ.
  • Taskbar ແລະ ຖາດລະບົບ. ຈຳນວນຂໍ້ຄວາມທີ່ຍັງບໍ່ໄດ້ອ່ານຢູ່ເທິງໄອຄອນ, ເລີ່ມພ້ອມ Windows, ແລະ ເລືອກໃຫ້ເຮັດວຽກຕໍ່ຢູ່ຖາດລະບົບເມື່ອປິດໜ້າຕ່າງໄດ້.
  • ຄວາມເປັນສ່ວນຕົວ. ເຊື່ອງສະຖານະກຳລັງພິມ, ເຊື່ອງຊື່ ແລະ ຮູບໂປຣໄຟລ໌ເວລາແບ່ງປັນໜ້າຈໍ, ແລະ ບລັອກຄຳຂໍວິເຄາະຂໍ້ມູນຂອງ Facebook (ເປີດໄວ້ຕັ້ງແຕ່ຕົ້ນ).
  • ພາສາລາວ. Chatpane ໃຊ້ພາສາຂອງຄອມພິວເຕີເຈົ້າ, ແລະ ເມນູ ແລະ ການຕັ້ງຄ່າຂອງມັນມີພາສາລາວ. ຖ້າ Windows ຂອງເຈົ້າເປັນພາສາອັງກິດ, ເຈົ້າປ່ຽນເປັນພາສາລາວໄດ້ທີ່ ການຕັ້ງຄ່າ → ທົ່ວໄປ → ພາສາ.

ວິທີຕິດຕັ້ງ

  1. ດາວໂຫຼດຕົວຕິດຕັ້ງສຳລັບ Windows. ຖ້າຄອມຂອງເຈົ້າໃຊ້ຊິບ ARM, ໃຫ້ໃຊ້ຕົວຕິດຕັ້ງ ARM64.
  2. ເປີດໄຟລ໌ທີ່ດາວໂຫຼດມາ. ຕົວຕິດຕັ້ງ Chatpane ສຳລັບ Windows ຍັງບໍ່ມີລາຍເຊັນດິຈິຕອນ, ສະນັ້ນ SmartScreen ອາດຂຶ້ນວ່າ "Windows protected your PC". ໃຫ້ຄລິກ "More info" ແລ້ວຄລິກ "Run anyway". ດາວໂຫຼດ Chatpane ຈາກ chatpane.app ຫຼື GitHub ເທົ່ານັ້ນ.
  3. ລ໋ອກອິນດ້ວຍບັນຊີ Facebook ເກົ່າຂອງເຈົ້າ. ແຊັດຈະຂຶ້ນມາທັນທີ.

ບໍ່ຢາກຕິດຕັ້ງຫຍັງເລີຍບໍ? ເວີຊັນພົກພາ (.zip) ໃຊ້ໄດ້ໂດຍບໍ່ຕ້ອງຕິດຕັ້ງ.

ຄຳຖາມທີ່ພົບເລື້ອຍ

ຄຳຖາມກ່ຽວກັບ Messenger ຢູ່ຄອມ

Chatpane ຟຣີບໍ?

ຟຣີ. ບໍ່ມີຄ່າໃຊ້ຈ່າຍ, ບໍ່ມີຄ່າສະມາຊິກ ແລະ ບໍ່ມີໂຄສະນາ. Chatpane ເປັນໂອເພນຊອດພາຍໃຕ້ໃບອະນຸຍາດ MIT, ແລະ ໂຄດຂອງມັນເຜີຍແຜ່ຢູ່ GitHub ໃຫ້ທຸກຄົນກວດສອບໄດ້.

ນີ້ແມ່ນແອັບ Messenger ທາງການບໍ?

ບໍ່ແມ່ນ. Chatpane ເປັນໂປຣເຈັກອິດສະຫຼະ, ບໍ່ກ່ຽວຂ້ອງກັບ Meta. ມັນສະແດງ Messenger ໂຕຈິງຈາກ facebook.com/messages ໃນໜ້າຕ່າງຂອງມັນເອງ, ສະນັ້ນ ຂໍ້ຄວາມຂອງເຈົ້າຍັງສົ່ງຜ່ານ Messenger ແລະ ເງື່ອນໄຂຂອງ Meta ກໍຍັງມີຜົນຄືເກົ່າ.

ບໍ່ມີບັນຊີ Facebook ໃຊ້ໄດ້ບໍ?

ບໍ່ໄດ້. ຕັ້ງແຕ່ເດືອນເມສາ 2026, Meta ໃຫ້ໃຊ້ Messenger ໂດຍບໍ່ມີບັນຊີ Facebook ໄດ້ສະເພາະໃນແອັບມືຖື. ຢູ່ຄອມ, ທັງ Chatpane ແລະ ທຸກວິທີອື່ນ ຕ້ອງໃຊ້ບັນຊີທີ່ເຂົ້າ facebook.com ໄດ້.

ໃຊ້ກັບ Windows 10 ໄດ້ບໍ?

ໄດ້, ທັງ Windows 10 ແລະ 11. Chatpane ໃຊ້ Microsoft Edge WebView2 ເຊິ່ງມີຢູ່ແລ້ວໃນ Windows 11. ຢູ່ Windows 10, ຕົວຕິດຕັ້ງຈະດາວໂຫຼດໃຫ້ ຖ້າຍັງບໍ່ມີ.

ໂທວິດີໂອໄດ້ບໍ?

ໄດ້. ນີ້ແມ່ນ Messenger ເຕັມຮູບແບບ, ສະນັ້ນ ການໂທດ້ວຍສຽງ ແລະ ວິດີໂອຈະເປີດໃນໜ້າຕ່າງຂອງມັນເອງ, ຄືກັນກັບຢູ່ facebook.com.
